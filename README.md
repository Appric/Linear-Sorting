# Linear Sorting

Algorithms and Optimizations Collaboration

Compares the timing of linear and comparison sort algorithms (counting sort and heap sort) on various sizes of data. Also compares with a parallel version of merge sort. Then prints the top 10 rated entries from our generated data.

Our generated data set is stored into an vector of structs. The various sorting algorithms output the sorted structs into a second vector. The implementation of counting sort uses a vector of queues which contain structs.
